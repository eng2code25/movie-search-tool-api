# Movie Search Tool

## What this is
A movie search app that fetches data from an external API.

## Features
- Search movies by title
- Fetch data from API
- Display results dynamically
- Loading and error states

## Live link
https://movie-search-tool-api.vercel.app/

## What I learned
- Async JavaScript (fetch, async/await)
- Handling API responses
- Error handling (try/catch)
- Working with real data

## Notes
This was my first project working with external data instead of static content.
